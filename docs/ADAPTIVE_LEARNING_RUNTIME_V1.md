# Phase 9 — Adaptive Learning Runtime v1

Platform-independent runtime for prerequisite-aware mastery, recommendations,
practice selection, analytics, coach summaries, persistence, and deterministic replay.

## Commands

```bash
npm run academy:v1:build
npm run academy:v1:test
npm run phase9:test
```

`phase9:test` runs the Phase 7 and Phase 8 regression suites before Phase 9.
