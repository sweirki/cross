# Application Layer — Milestone 2.3: Progression

## Included

- Deterministic XP and level thresholds
- Puzzle, lesson, campaign, daily, mastery, speed, accuracy, and hint-free XP bonuses
- Achievement and badge catalog
- Daily streak and longest-streak tracking
- Lifetime player statistics
- Ordered reward queue
- Duplicate-completion protection
- Canonical persistence and restore validation
- React Native progression provider
- Sequential reward overlay
- Enhanced profile with level, XP, streaks, metrics, and badge collection

## Commands

```bash
npm run progression:m23:build
npm run progression:m23:test
npm run milestone2.3:test
npx expo start --clear
```
